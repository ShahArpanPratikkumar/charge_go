# ChargeGo - Next-Gen Power Sharing

A production-ready React website for a portable energy sharing service, converted from a premium Figma design.

## Tech Stack
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **React Router** (Navigation)

## Features
- **Hero Section**: High-impact brand presence with neon aesthetics.
- **Network Stats**: Real-time business metrics visualization.
- **Connectivity**: IoT integration showcase with kinetic animations.
- **Map Interface**: Interactive station finder with filtering and availability tracking.
- **Dashboard**: Personal usage center with live battery/rental tracking.
- **Auth Flow**: Sleek Sign In and Sign Up pages.
- **Responsive**: Mobile-first design that looks great on all devices.

## Getting Started

1. **Install Dependencies**
   ```bash
   cd frontend
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## Design Principles
- **Theme**: Futuristic Dark Mode
- **Primary Color**: Neon Cyan (#00D2FF)
